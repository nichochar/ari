# Local web fonts

Unmodified WOFF2 files from [Google Fonts CSS](https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600;700&family=Newsreader:opsz,wght@6..72,400;6..72,500&display=swap), downloaded 2026-10-28 using a modern Chrome user agent. `src/fonts.css` preserves the returned normal styles, weights, Unicode subsets and `font-display: swap`. Newsreader retains its optical-size axis. No font family, weight or typography settings were changed.
